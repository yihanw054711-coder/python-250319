
1.容器数据类型
    列表 list
        list是可变的，可以对list中的元素进行修改
        list是有序的，每个元素都有对应的下标（索引），可以通过索引访问list中的元素以及对list进行切片操作
        list中可以存放不同类型的元素
        list中可以存放重复的元素
        使用[]定义list

    字符串 str
        str是不可变的，不能直接对str中的元素进行修改，如果修改的话会创建新的对象
        str是有序的，每个字符都有对应的下标（索引），可以通过索引访问str中的字符以及对str进行切片操作
        str中只能存放字符串类型的元素
        使用''或""或“”“”“”（需要配合使用）定义str

    元组 tuple
        tuple是不可变的，不能直接对元组中的元素进行修改
        tuple是有序的，每个元素都有对应的下标（索引），可以通过索引访问tuple中的元素以及对tuple进行切片操作
        tuple可以存放不同类型的数据
        使用()定义tuple

    集合 set
        set是可变的，可以对set中的元素进行修改，可以向set中添加元素和删除元素
        set中元素不能重复
        set是无序的，没有对应的下标（索引），不能通过索引访问set中的元素以及对set进行切片操作
        set中只能存放不可变类型的数据（如字符串、数字、元组等），不能存放可变类型的数据（如列表、字典等）
        使用{}定义set或者set()

    字典 dict
        以k-v键值对的形式存储数据的 key:value
        其中key部分内容是不可变的，必须是不可变类型的数据（如字符串、数字、元组等）
        其中value部分内容是可变的，可以是任意类型的数据
        dict是可变的，可以对dict中的元素进行修改，可以向dict中添加元素和删除元素
        dict是无序的，没有对应的下标（索引），不能通过索引访问dict中的元素以及对dict进行切片操作
        使用{}定义dict或者dict()
        dict的key必须唯一，value可以重复
2.各种容器类型对比
    数据结构	            是否可变	    是否重复	        是否有序	                            定义符号
    列表（List）	        可变	        允许	            有序	                                []或list()
    元组（Tuple）	    不可变	    允许	            有序	                                ()或tuple()
    字典（Dictionary）	可变	        键不允许，值允许	键无序（Python 3.7+版本中保持插入顺序）	{}或dict()
    集合（Set）	        可变	        不允许	        无序	                                {}或set()
