## 📚 学习分类

### 课程学习
```dataview
TABLE 
  file.ctime as "创建时间",
  status as "状态"
FROM "01-学习/课程笔记"
SORT file.ctime DESC
```

### 读书笔记
```dataview
TABLE 
  author as "作者",
  status as "状态",
  rating as "评分"
FROM "01-学习/读书笔记"
SORT rating DESC, file.ctime DESC
```

### 研究专题
```dataview
TABLE 
  file.ctime as "创建时间",
  tags as "标签"
FROM "01-学习/研究笔记"
SORT file.ctime DESC
```

## 📈 学习进展

### 月度学习总结
```dataview
CALENDAR file.ctime
FROM "01-学习"
WHERE file.ctime >= date(today) - dur(30 days)
```

### 学习时间统计
```dataview
TABLE 
  sum(duration) as "总学习时间"
FROM "01-学习"
WHERE duration
GROUP BY file.folder
```

## 🎓 学习成果

### 已完成课程
```dataview
TABLE 
  completion_date as "完成日期",
  certificate as "证书"
FROM "01-学习/课程笔记"
WHERE status = "已完成"
SORT completion_date DESC
```

### 已读书籍
```dataview
TABLE 
  author as "作者",
  rating as "评分",
  finish_date as "完成日期"
FROM "01-学习/读书笔记"
WHERE status = "已读"
SORT finish_date DESC
```
