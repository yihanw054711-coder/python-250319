# 安全政策 (Security Policy)

## 支持的版本

本项目为个人学习仓库，代码仅用于学习目的。

## 报告安全问题

如果你发现本仓库中存在安全隐患（例如意外提交了敏感信息、密钥、密码等），请**不要**公开提交 Issue，而是通过以下方式私下联系：

- 通过 GitHub 私信联系仓库所有者
- 或发送邮件说明情况

我会尽快处理并移除相关敏感信息。

## 注意事项

- 本仓库不应包含任何真实的密钥、密码、Cookie 或个人隐私数据
- 学习代码中如涉及网络请求（如爬虫练习），请遵守目标网站的使用协议，仅用于学习
- 请勿将本仓库代码用于任何非法或商业用途

感谢你帮助维护本项目的安全！🔒
