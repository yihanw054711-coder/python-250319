# 贡献者行为准则 (Code of Conduct)

## 我们的承诺

为了营造开放、友好的环境，我们承诺让每一位参与者都能获得无骚扰的体验，无论其年龄、体型、身体健全与否、民族、性别认同与表达、经验水平、国籍、外表、种族、宗教信仰或性取向如何。

## 行为准则

有助于营造积极环境的行为包括：

- 使用友善和包容的语言
- 尊重不同的观点和经历
- 优雅地接受建设性的批评
- 关注对社区最有利的事情
- 对其他社区成员表示同理心

不可接受的行为包括：

- 使用带有性暗示的言语或图像，以及不受欢迎的性关注
- 挑衅、侮辱或贬损性评论，以及人身或政治攻击
- 公开或私下的骚扰
- 未经明确许可，发布他人的私人信息（如住址、邮箱等）
- 其他在专业场合中被合理认定为不适当的行为

## 责任范围

项目维护者有权利和责任删除、编辑或拒绝不符合本行为准则的评论、提交、代码、issue 及其他贡献。

## 适用范围

本行为准则适用于所有项目空间，以及个人代表项目或其社区的公共场合。

## 执行

如遇到违反行为准则的情况，可通过 GitHub Issue 或邮件联系项目维护者。所有投诉都会被审查和调查。

## 归属

本行为准则改编自 [Contributor Covenant](https://www.contributor-covenant.org/) 2.0 版。
