
1. for循环
    语法：
        for 临时变量 in 可迭代对象：
            循环体
        else:
            所有循环结束之后，执行的代码
    说明：
        for是一个关键字
        临时变量用于接收从可迭代对象中取出的元素
        in是一个关键字
        可迭代对象是循环遍历的目标
        在for行要加“：”结束
        循环体是进入到循环后，要执行的代码块

    执行流程：
        当循环执行的时候，先从可迭代对象中取出一个元素
        如果有元素取出，将取出的元素复制给临时变量，进入到循环体，执行循环体代码循环体执行完毕之后，继续取下一个元素
        如果没有元素取出，循环结束

2.range()函数
    作用：生成可迭代的数列
    语法：
        range(start, stop, step)
        start:生成数列的起始值（包含） 可以省略 默认值为0
        stop:生成数列的结束值（不包含）
        step:步长-生成数字之间的差 可以省略 默认值为1
            如果为正数：生成的序列是递增的，要求起始值小于结束值
            如果为负数：生成的序列是递减的，要求起始值

3.循环嵌套
    说明：在一个循环体内又包含一个循环，这就是循环嵌套
    执行流程：
        外层循环执行一次，进入到内层循环，内层循环执行完毕之后，外层循环继续执行下一次，进入到内层循环，内层循环执行完毕之后，外层循环继续执行下一次，以此类推，直到外层循环结束

4.循环相关的关键字
    continue
        跳出当前循环，继续执行下一次循环
    break
        跳出当前循环，结束循环
    pass
        占位符，表示什么都不做，可以用在需要代码但暂时不想写代码的地方

6.序列（Sequence）
    是一种基本且核心的数据结构，它允许我们以有序的方式存储和操作数据。序列可以包含不同类型的元素，并且支持通过索引来访问和修改这些元素。
    常见的序列类型包括：列表（List）、元组（Tuple）、字符串（String）。

7.5.2 列表List
    列表是一个可变的、有序的元素集合。注意：这里的有序不是排序，指的是元素先来后到的顺序（放进来和取出去的顺序一致）
    列表使用 [] 定义，数据之间使用 , 分隔。
    列表中元素可以是不同的类型。
    列表中的元素是可以重复的。
    列表中每个元素都有对应的位置值，称为索引或下标，索引从起始从0开始向后逐个递增，并且从末尾从-1开始逐个向前递减。

8.切片
    从序列中按照规则取出其中某一部分
    list切片(三参数和range()函数所包含的参数一样）
        list[start:stop:step]
        start:切片的起始索引（包含） 可以省略 默认值为0
        stop:切片的结束索引（不包含） 可以省略 默认值为len(list)
        step:切片的步长-切片元素之间的差 可以省略 默认值为1
            如果为正数：生成的切片是递增的，要求起始索引小于结束索引
            如 果为负数：生成的切片是递减的，要求起始索引大于结束索引
