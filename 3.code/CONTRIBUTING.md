# 贡献指南 (Contributing)

感谢你对本项目的关注！这是一个个人 Python 学习仓库，主要用于记录学习历程。

## 如何贡献

虽然这是个人学习仓库，但仍欢迎以下形式的交流：

### 🐛 报告问题
如果你发现代码中的错误或有更好的实现建议，欢迎：
1. 提交 [Issue](../../issues) 描述问题
2. 说明相关的文件路径（如 `day08/P05_Class_Demo.py`）

### 💡 提出建议
- 更优雅的代码写法
- 更清晰的注释或笔记
- 学习资源推荐

### 🔧 提交代码 (Pull Request)
1. Fork 本仓库
2. 创建分支：`git checkout -b feature/your-idea`
3. 提交更改：`git commit -m "说明你的改动"`
4. 推送分支：`git push origin feature/your-idea`
5. 提交 Pull Request

## 代码规范

- 遵循 [PEP 8](https://peps.python.org/pep-0008/) Python 编码规范
- 变量/函数用小写下划线命名（`snake_case`），类用大驼峰（`CamelCase`）
- 适当添加注释，说明代码意图
- commit message 写清楚做了什么（如"新增 day12 装饰器练习"）

## 行为准则

参与本项目请遵守 [行为准则](CODE_OF_CONDUCT.md)。
